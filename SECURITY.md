# Security Policy

CaYa Coding Agent can modify files and optionally execute development tools on a user's computer. Please read the full security guide before deploying it:

**[docs/SECURITY.md](docs/SECURITY.md)**

## Reporting a vulnerability

Please do not include real Session IDs, Session Secrets, source code, private repository contents, or other credentials in a public issue.

When reporting a security problem, provide the minimum reproduction information necessary and replace all credentials with placeholders.

## Current maturity

v0.1.x is a reference implementation / early MVP. It is suitable for controlled personal testing and development, not as-is for a public multi-tenant service.
